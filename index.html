Small on purpose

Big rewrites get stuck in review. Tiny changes get merged.

🪶

One change per PR

A typo, a clearer error message, a missing doc line. Each pull request does exactly one thing, so it's easy to review and easy to revert.

🔍

One issue at a time

Issues that are specific, reproducible and kind. One problem per issue, with enough detail for a maintainer to act on it.

🌊

Steady, like water

Small improvements compound. A swan looks calm on the surface; the progress comes from consistent, quiet paddling.

How I work

The same loop, every project.

Pick one projectSomething I use or care about, with room to be a little better.
Spot one tiny thingA broken link, an unclear README step, a small bug, a missing test.
Open an issue or a PRSmall, focused, well described. Never more than one idea at a time.
Learn from the reviewTake feedback gracefully, adjust, and move on to the next tiny change.
